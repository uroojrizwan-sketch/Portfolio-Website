About Me

I'm a BS Computer Science student at the University of Haripur with a strong interest in frontend and web application development.

I work with HTML, CSS, JavaScript and React to build responsive websites and interactive applications. Through hands-on projects, I've practised component-based development, routing, state management, API integration, DOM manipulation and responsive UI design.

I enjoy learning by building, improving my problem-solving skills and exploring how modern web technologies can be used to create useful digital products. I'm currently strengthening my frontend skills while growing towards full-stack development and AI-powered web applications.
